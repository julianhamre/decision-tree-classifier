# ID3 Decision tree classifier

This project contains an implementation of the ID3 (Iterative Dichotomiser 3) algorithm,
a decision tree classifier.

Run [run_experiments.ipynb](run_experiments.ipynb) to see the model performance on an example dataset.  

The [dataset](churn-data.csv) is a preprocessed version of the [Telco Customer Churn](https://www.kaggle.com/datasets/blastchar/telco-customer-churn) dataset from kaggle.com.
