# ID3 Decision tree classifier

This project contains an implementation and evaluation of the ID3 (Iterative Dichotomiser 3) algorithm,
a decision tree classifier.
The project is my solution to Project 1 of the subject Introduction to Machine
learning (INF264) at UiB in 2026.

The [dataset](churn-data.csv) used for model evaluation 
is a preprocessed version of the [Telco Customer Churn](https://www.kaggle.com/datasets/blastchar/telco-customer-churn) dataset from kaggle.com.

See the [report](report/report.pdf) for an explanation of my implementation and results.

## How to reproduce my results
1. Install dependencies `pip install numpy pandas scikit-learn matplotlib`.
2. Run all cells in [run_experiments.ipynb](run_experiments.ipynb)
